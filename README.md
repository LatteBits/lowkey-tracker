## Reporting a Bug

If you run into an unexpected error, crash, or inaccurate key detection, we want to fix it as fast as possible. 

Before opening a new bug report, please **search the existing issues** to see if it has already been reported. If not, please open a new issue and provide the following details:

* **OS and Version:** (e.g., Windows 11, macOS Sonoma 14.2)
* **App Version:** (e.g., v1.0.0)
* **System Specs:** (CPU, RAM, Audio Interface if applicable)
* **Steps to Reproduce:** A quick step-by-step guide on how to trigger the bug.
* **Expected vs. Actual Behavior:** What you thought would happen vs. what actually happened.
* **Media:** Screenshots, screen recordings, or error logs if available.

## Requesting a Feature

Lowkey Audio Engine is built for the DJ community, and your workflow insights dictate our roadmap. If you have an idea to make the engine faster, smarter, or better integrated into your setup, we want to hear it!

When submitting a feature request, please include:
* **The Problem:** What current friction are you facing in your workflow?
* **The Solution:** How would your proposed feature solve this?
* **Use Case:** How does this apply to your specific DJ or production environment?

## Repository Guidelines

To keep this tracker organized and efficient for everyone, please adhere to a few basic rules:

1. **One topic per issue:** Please do not bundle multiple bugs or feature requests into a single post. Open separate issues for each so we can track them accurately.
2. **Check for duplicates:** Use the search bar before submitting a new issue. If you find an open issue that matches your idea or bug, give the original post a 👍 reaction so we can gauge community interest.
3. **Be respectful:** We are an indie team building this for you. Constructive feedback is always welcome, but please keep the discussion professional.

---

### Security & Privacy

If you have discovered a critical security vulnerability, please do **not** open a public issue. Email us directly at **support@lattebits.com** so we can investigate and patch it privately.
